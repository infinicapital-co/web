# Infini Capital — Website

Static website for Infini Capital, a proprietary quantitative investment firm focused on repeatable, risk-adjusted edges in liquid markets.

## What's here
- `index.html` — Homepage: company overview, approach, and contact
- `blackboard.html` — QFactory article: Blackboard architecture for research and trading workflows
- `orchestration.html` — QFactory article: Signal orchestration and automation layer

## Structure
This is a simple static site (HTML + CSS, no build step). Pages are linked through the top navigation; the QFactory dropdown connects the Blackboard and Orchestration articles.
